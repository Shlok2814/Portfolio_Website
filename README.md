## ✨ Features

- 🎭 **Dual-Persona Split Hero**: Interactive dual-mode landing page toggling seamlessly between **Code (Software Engineering)** and **Craft (Product Design)**.
- 🧊 **3D Interactive Rubik's Cube**: Built with Three.js and `@react-three/fiber` featuring mouse-driven physics, rotations, and smooth accent glow effects.
- ⚡ **Fluid Micro-Interactions**: Powered by Framer Motion for buttery-smooth page transitions, clip-path animations, and dynamic split sliders.
- 💼 **Project & Experience Showcases**: Highlighting full-stack applications, machine learning projects, leadership, internships, and certifications.
- 📱 **Fully Responsive**: Optimized for ultra-wide displays down to mobile screens with glassmorphism and modern dark aesthetics.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shlok2814/Portfolio_Website.git
   cd Portfolio_Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```
